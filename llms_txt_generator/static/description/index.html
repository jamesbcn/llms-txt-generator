LLMs.txt Generator for Odoo

SEO-Friendly AI & LLM Indexing File

The LLMs.txt Generator automatically creates a /llms.txt file for your Odoo 18 website, following the official llmstxt.org guidelines.

This file makes it easier for Large Language Models (LLMs) such as ChatGPT and other AI tools to discover and understand your public content, boosting your website’s visibility and discoverability in the AI era.

Main Features

  • Generates an /llms.txt file dynamically.
  • Includes all published web pages and blog posts.
  • Multi-language support: generates URLs for all active languages.
  • SEO-friendly format recommended by llmstxt.org.
  • No hardcoding — everything is pulled from your live Odoo site.

Installation

  1. Download and install the module in your Odoo 18 instance.
  2. Activate it from the Apps menu.
  3. Visit https://yourdomain.com/llms.txt to see the generated file.

Why Use This Module?

Traditional SEO sitemaps are for search engines like Google. llms.txt is for AI models. By installing this module, your content is more likely to be indexed, referenced, and used by AI assistants.
